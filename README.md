# Travel Classics Database Management System

A relational database management system designed for **Travel Classics (TC)**, a tourism company that provides travelers with information about hotels, accommodation facilities, destinations, travel experiences, and hotel reservations.

## Project Overview

Travel Classics plans to provide an online platform where travelers can search for hotels based on country, city, and street, while registered hotels can manage their hotel information and accommodation options.

The database system supports travelers, hotels, facilities, accommodation options, reservations, travel reports, and payment transactions.

## Main Features

- Traveler registration and information management
- Hotel registration and hotel information management
- Hotel search by country, city, and street
- Hotel facility management
- Accommodation category and room availability management
- Hotel room reservations
- Multiple room reservations per traveler
- Guest information management
- Travel experience reports
- Reservation payment tracking
- Transaction records with unique transaction IDs

## Database Design

The database was designed using the relational database model and includes:

- Entity Relationship Diagram (ERD)
- Relational schema
- Primary keys and foreign keys
- Database normalization up to Third Normal Form (3NF)
- SQL Server database implementation
- SQL queries for data retrieval and manipulation

## SQL Queries

The project includes SQL queries for requirements such as:

- Listing travelers from a particular location
- Calculating transactions received by a particular hotel within a given duration
- Listing hotels and their room availability
